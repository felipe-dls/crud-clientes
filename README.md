# CRUD de Clientes

Projeto desenvolvido para a disciplina de JavaScript Front-end.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Criar clientes
- Listar clientes
- Editar clientes
- Excluir clientes
- Layout responsivo

## Responsividade

A aplicação adapta-se para:

- Desktop
- Tablet
- Smartphone

## API

A aplicação é apenas Front-end.

As chamadas REST estão comentadas no arquivo `script.js`.

Exemplos:

```javascript
// GET /clientes

// POST /clientes

// PUT /clientes/{id}

// DELETE /clientes/{id}
```
